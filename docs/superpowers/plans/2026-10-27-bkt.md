# Log-space BKT with per-item emissions: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `BKT` predictor (two-state HMM per skill, one transition per checkpoint, batched log-space emissions, per-item guess/slip shrunk toward an anchor with optional recency) scored on OLMo-2 MMLU against the item-mean bar at h = 1, 5, 20, with a mastery figure and a write-up.

**Architecture:** One new module `src/llm_kt/bkt.py` with pure functions (`batch_log_emissions`, `log_forward_backward`, `fit_skill`, `forecast_state`) and a `BKT` class that satisfies `llm_kt.evaluate.Predictor`, caching per-skill parameters between walk-forward origins the way `DriftIRT` does. `scripts/run_models.py` grows a `bkt` option; a new `scripts/analyze_bkt.py` selects on validation, compares with `item_mean`, and draws the mastery figure.

**Tech Stack:** Python 3.12, numpy, scipy (`logsumexp`), pandas, matplotlib, pytest, ruff (line length 100). Run tests with `PYTHONPATH=src .venv/bin/python -m pytest`.

**Spec:** `docs/superpowers/specs/2026-10-27-bkt-design.md`

## Global Constraints

- Predictor protocol: `predict(history, target, horizon=1) -> np.ndarray` of finite probabilities in [0, 1], one per target row, in order (`src/llm_kt/evaluate.py:45`).
- Clock is `checkpoint_idx`; horizon `h` means `h` transition steps.
- Constraint `guess <= 1 - slip - 0.05` at skill level and item level, applied to anchors and to estimates; clip guess downward.
- Probabilities used inside logs are clipped to `[1e-6, 1 - 1e-6]`.
- Cold-start values: `pi = 0.2, learn = 0.1, forget = 0.02, guess_s = 0.25, slip_s = 0.3`; pseudo-count prior `prior_count = 1.0` at those values for the skill-level M-step.
- EM: `max_iter = 50`, stop when mean log-likelihood per observation changes by `< 1e-5`.
- Predictor name: `bkt_k{kappa:g}_r{rho:g}_{anchor}` plus `_lo{theta_lo:g}_hi{theta_hi:g}` when `anchor == "fluid"`.
- Fluid anchor: `guess_i^0 = prob_logistic(theta_lo, a_i, b_i)`, `1 - slip_i^0 = prob_logistic(theta_hi, a_i, b_i)` (`src/llm_kt/static_irt.py:46`, logistic scale, no probit conversion).
- Experiments: OLMo-2, `--benchmarks mmlu`, `min_history 2`; select on the validation block only; report test once.
- Commit messages: plain, no attribution trailer of any kind (standing rule).
- Everything goes on `bhagyesh_branch`.

## Review Focus

1. A history with only two checkpoints (the first walk-forward origin): EM must return finite parameters and `predict` finite probabilities. Test in Task 3 (`test_two_checkpoint_history_is_finite`).
2. A skill whose items are all correct (or all wrong) at every checkpoint: no `log(0)`; parameters stay inside the clip bounds. Test in Task 2 (`test_degenerate_all_correct_skill_is_finite`).
3. Items missing at some checkpoints (NaN cells in the item × checkpoint matrix): masked out of the emission sums and the M-step, not treated as wrong. Test in Task 3 (`test_missing_cells_are_ignored`).
4. Under the Fluid anchor, an item with no Fluid parameters falls back to the skill anchor instead of raising or producing NaN. Test in Task 3 (`test_fluid_anchor_item_without_params_uses_skill_anchor`).
5. Shuffled target rows return predictions in the shuffled order. Test in Task 3 (`test_shape_alignment_and_range`).

  - `class FBResult(NamedTuple)`: `gamma: np.ndarray (T, 2)` smoothed posteriors, `xi: np.ndarray (2, 2)` summed pairwise posteriors (`xi[i, j]` = expected count of transitions `i -> j`), `filtered: np.ndarray (T, 2)` normalised forward probabilities `P(z_t | y_{0..t})`, `loglik: float`.
  - `log_forward_backward(log_pi: np.ndarray, log_A: np.ndarray, log_emit: np.ndarray) -> FBResult` with `log_A[i, j] = log P(z_{t+1} = j | z_t = i)`.

```python
# tests/test_bkt.py
import numpy as np
import pytest
from scipy.special import logsumexp
from llm_kt.bkt import batch_log_emissions, log_forward_backward

def brute_force(log_pi, log_A, log_emit):
    T = log_emit.shape[0]
    paths = np.array(np.meshgrid(*[[0, 1]] * T, indexing="ij")).reshape(T, -1).T  # (2^T, T)
    lp = np.array([log_pi[p[0]] + log_emit[0, p[0]]
                   + sum(log_A[p[t - 1], p[t]] + log_emit[t, p[t]] for t in range(1, T)) for p in paths])
    loglik = logsumexp(lp)
    w = np.exp(lp - loglik)
    gamma = np.stack([(w * (paths[:, t] == 1)).sum() for t in range(T)])
    xi = np.zeros((2, 2))
    for i in range(2):
        for j in range(2):
            xi[i, j] = sum((w * ((paths[:, t - 1] == i) & (paths[:, t] == j))).sum() for t in range(1, T))
    return gamma, xi, loglik

class TestForwardBackward:
    def test_matches_brute_force(self):
        rng = np.random.default_rng(0)
        T = 5
        log_pi = np.log(np.array([0.7, 0.3]))
        log_A = np.log(np.array([[0.8, 0.2], [0.1, 0.9]]))
        log_emit = rng.normal(0, 3, (T, 2))
        res = log_forward_backward(log_pi, log_A, log_emit)
        g, xi, ll = brute_force(log_pi, log_A, log_emit)
        assert res.loglik == pytest.approx(ll)
        assert res.gamma[:, 1] == pytest.approx(g)
        assert res.gamma.sum(axis=1) == pytest.approx(np.ones(T))
        assert res.xi == pytest.approx(xi)
        assert res.filtered[-1] == pytest.approx(res.gamma[-1])   # smoothing = filtering at the last step
        assert res.filtered.sum(axis=1) == pytest.approx(np.ones(T))

    def test_no_underflow_with_many_items(self):
        rng = np.random.default_rng(1)
        N, T = 2000, 6
        Y = (rng.random((N, T)) < 0.6).astype(float)
        le = batch_log_emissions(Y, np.full(N, 0.25), np.full(N, 0.2))
        assert le.shape == (T, 2) and np.all(np.isfinite(le)) and (le < -100).all()
        res = log_forward_backward(np.log([0.5, 0.5]), np.log([[0.9, 0.1], [0.05, 0.95]]), le)
        assert np.all(np.isfinite(res.gamma)) and np.isfinite(res.loglik)

    def test_emissions_mask_nan_cells_and_clip(self):
        Y = np.array([[1.0, np.nan], [0.0, 1.0]])
        le = batch_log_emissions(Y, np.array([0.0, 0.5]), np.array([1.0, 0.5]))  # guess 0 / slip 1 get clipped
        assert np.all(np.isfinite(le))
        assert le[1, 0] == pytest.approx(np.log(0.5))   # only item 1 observed at t=1: y=1 under z=0 -> log guess
        assert le[1, 1] == pytest.approx(np.log(0.5))
```

```python
from llm_kt.bkt import COLD_START, EPS, SkillParams, clip_guess, fit_skill, forecast_state

def simulate_skill(rng, N, T, pi, learn, forget, guess, slip):
    z = np.zeros(T, dtype=int); z[0] = rng.random() < pi
    for t in range(1, T):
        z[t] = (rng.random() < learn) if z[t - 1] == 0 else (rng.random() >= forget)
    p = np.where(z[None, :] == 1, 1 - slip[:, None], guess[:, None])
    return (rng.random((N, T)) < p).astype(float), z

    def test_clip_guess_keeps_learned_state_better(self):

        assert g == pytest.approx([0.65, 0.2, 1e-6])

    def test_forecast_state_moves_toward_stationary(self):

        stat = learn / (learn + forget)
        p = [forecast_state(0.0, learn, forget, h) for h in (1, 5, 20)]
        assert p[0] == pytest.approx(0.1) and p[0] < p[1] < p[2] < stat
        assert forecast_state(1.0, learn, forget, 1) == pytest.approx(0.95)

        assert 1 <= fp.n_iter <= 50 and np.isfinite(fp.loglik)
```

- [ ] **Step 3: Implement `COLD_START`, `clip_guess`, `forecast_state`, `SkillParams`, `fit_skill` in `src/llm_kt/bkt.py`**

M-step formulas (spec §4), with `c = prior_count`, `m0 = COLD_START`, `g = gamma[:, 1]`, `M` the observed mask, `w_t = rho ** (T - 1 - t)`:

```
pi       = (g[0] + c m0.pi) / (1 + c)
learn    = (xi[0,1] + c m0.learn) / (xi[0,0] + xi[0,1] + c)
forget   = (xi[1,0] + c m0.forget) / (xi[1,0] + xi[1,1] + c)
guess_s  = (sum M (1-g) Y + c m0.guess_s) / (sum M (1-g) + c)
slip_s   = (sum M g (1-Y) + c m0.slip_s) / (sum M g + c)           then guess_s = clip_guess(guess_s, slip_s)
guess_i  = (sum_t w_t M (1-g) Y + kappa g0_i) / (sum_t w_t M (1-g) + kappa)
slip_i   = (sum_t w_t M g (1-Y) + kappa s0_i) / (sum_t w_t M g + kappa)   then guess_i = clip_guess(guess_i, slip_i)
```

where `(g0_i, s0_i)` is `(guess_s, slip_s)` for the skill anchor or the clipped Fluid arrays. Rates clipped to `[EPS, 1 - EPS]`. Loop: E-step (`batch_log_emissions` + `log_forward_backward`), M-step, stop when `|loglik_new - loglik_old| / M.sum() < tol` or `max_iter`. Return `n_iter` = iterations run.

  - `BKT.fit(self, history: pd.DataFrame) -> None`: builds the item × checkpoint matrix (`history.pivot_table(index="item_id", columns="checkpoint_idx", values="correct")`, one pivot, sliced per skill by an item → skill map), runs `fit_skill` per skill with warm start from the cache when the history extends the cached one (fingerprint as `DriftIRT._fingerprint`), else cold.
  - `BKT.predict(self, history, target, horizon=1) -> np.ndarray` per spec §3; unseen item → anchor values; unseen skill → last-checkpoint global accuracy; output clipped to `[EPS, 1 - EPS]`.
  - `BKT.mastery(self) -> pd.DataFrame` with columns `skill, checkpoint_idx, p_learned` (filtered `P(z_t = 1)`) for the last fitted history.
  - `BKT.skill_params(self) -> pd.DataFrame` with columns `skill, n_items, pi, learn, forget, guess_s, slip_s, n_iter`.

```python
        m = BKT(kappa=1e6, anchor="fluid", item_params=params, theta_lo=-1.0, theta_hi=1.0)
        target = target_at(hist, 15)
        p = m.predict(hist[hist["item_id"] != ids[0]], target)[0]
        a, b = params["a"].iloc[0], params["b"].iloc[0]
        g, hi = prob_logistic(-1.0, a, b), prob_logistic(1.0, a, b)
        g = min(g, hi - MIN_GAP)
        z = forecast_state(m.mastery().query("skill == 's0'")["p_learned"].iloc[-1], *m.skill_params().set_index("skill").loc["s0", ["learn", "forget"]], 1)
        assert p == pytest.approx(z * hi + (1 - z) * g, abs=1e-6)

    def test_fluid_anchor_item_without_params_uses_skill_anchor(self, world):
        params, hist, ids, _ = world
        m = BKT(kappa=1e6, anchor="fluid", item_params=params.iloc[1:])
        p = m.predict(hist, target_at(hist, 15))
        sp = m.skill_params().set_index("skill").loc["s0"]
        z = forecast_state(m.mastery().query("skill == 's0'")["p_learned"].iloc[-1], sp["learn"], sp["forget"], 1)
        assert p[0] == pytest.approx(z * (1 - sp["slip_s"]) + (1 - z) * sp["guess_s"], abs=1e-6)

    def test_unseen_skill_falls_back_to_global_mean(self, world):
        _, hist, _, _ = world
        target = target_at(hist, 15).copy()
        target.loc[0, "skill"] = "never_seen"; target.loc[0, "item_id"] = "mmlu_new"
        p = BKT().predict(hist, target)
        last = hist[hist["checkpoint_idx"] == 14]
        assert p[0] == pytest.approx(last["correct"].mean())

    def test_two_checkpoint_history_is_finite(self, world):
        _, hist, _, _ = world
        short = hist[hist["checkpoint_idx"] <= 1]
        p = BKT(kappa=5.0, rho=0.7).predict(short, target_at(short, 2))
        assert np.all(np.isfinite(p)) and ((p > 0) & (p < 1)).all()

    def test_missing_cells_are_ignored(self, world):
        _, hist, ids, _ = world
        holed = hist[~((hist["item_id"] == ids[0]) & (hist["checkpoint_idx"].isin([5, 6, 7])))]
        p = BKT(kappa=5.0).predict(holed, target_at(hist, 15))
        assert np.all(np.isfinite(p))
        full = BKT(kappa=5.0).predict(hist, target_at(hist, 15))
        assert abs(p[0] - full[0]) < 0.2 and p[1:] == pytest.approx(full[1:], abs=0.05)

    def test_cache_warm_start_close_to_cold_and_resets(self, world):
        _, hist, _, _ = world
        target = target_at(hist, 15)
        m = BKT(kappa=5.0)
        for t in (4, 9):
            m.predict(hist[hist["checkpoint_idx"] <= t], target)
        assert m.predict(hist, target) == pytest.approx(BKT(kappa=5.0).predict(hist, target), abs=0.02)
        other = hist.assign(correct=1 - hist["correct"])
        assert m.predict(other, target) == pytest.approx(BKT(kappa=5.0).predict(other, target))
        short = hist[hist["checkpoint_idx"] <= 4]
        assert m.predict(short, target) == pytest.approx(BKT(kappa=5.0).predict(short, target))

    def test_mastery_and_skill_params_shapes(self, world):
        _, hist, _, _ = world
        m = BKT(kappa=5.0); m.fit(hist)
        ms = m.mastery()
        assert list(ms.columns) == ["skill", "checkpoint_idx", "p_learned"] and len(ms) == 2 * 15
        assert ms["p_learned"].between(0, 1).all()
        sp = m.skill_params()
        assert list(sp.columns) == ["skill", "n_items", "pi", "learn", "forget", "guess_s", "slip_s", "n_iter"]
        assert sp["n_items"].tolist() == [100, 100]

    def test_runs_in_harness(self, world):
        _, hist, _, _ = world
        res = evaluate(hist, [BKT(kappa=5.0), ItemMean()], horizon=2)
        assert set(res["predictor"]) == {"bkt_k5_r1_skill", "item_mean"} and res["log_loss"].notna().all()

    def test_name_and_validation(self):
        params = pd.DataFrame({"item_id": ["x"], "a": [1.0], "b": [0.0]})
        assert BKT(kappa=20, rho=0.9).name == "bkt_k20_r0.9_skill"
        assert BKT(kappa=1e6, anchor="fluid", item_params=params, theta_lo=-2, theta_hi=1).name == "bkt_k1e+06_r1_fluid_lo-2_hi1"
        for kw in (dict(anchor="logit"), dict(kappa=0), dict(rho=0), dict(rho=1.5),
                   dict(anchor="fluid"), dict(anchor="fluid", item_params=params, theta_lo=1, theta_hi=1)):
            with pytest.raises(ValueError):
                BKT(**kw)
        assert ANCHORS == ("skill", "fluid")
```
